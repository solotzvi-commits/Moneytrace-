# MONEYTRACE — אפליקציית מעקב הוצאות

אפליקציה עברית RTL, כהה ומותאמת למובייל.

## הרצה מקומית
```bash
python3 -m http.server 8080
```
פתח `http://localhost:8080`.

## מה עובד
- לוח בקרה, הכנסות והוצאות חודשיות.
- הוספה ומחיקה של תנועות.
- ייבוא וייצוא CSV.
- חלוקה לקטגוריות ותובנות.
- זיהוי היוריסטי של חיובים חוזרים.
- מחשבון חיסכון.
- PWA עם manifest ו-service worker.
- שמירת נתונים מקומית בדפדפן.

## מעטפת Android/iOS
נוסף `capacitor.config.json` ו-`package.json` להכנת מעטפת Capacitor. יש לפעול לפי `APP_STORE_RELEASE_GUIDE_HE.md`.

## מגבלות מהותיות
אין כרגע חיבור בנק אמיתי, backend, משתמשים, סנכרון, גיבוי או פרסום בחנויות. נתוני ההדגמה פיקטיביים. אין להזין סיסמת בנק או קוד אימות.
